## 已修复的重要 bug(记录)

| Bug | 影响 | 修复 |
| --- | --- | --- |
| stub log_agent 拿不到快照内容 | 专家分析失效 | agent 层已 resolve,stub 直接用内容 |
| expert 豁免重复调用检查 | 无意义循环不拦截 | 取消豁免(对齐论文 §III-C2) |

| 单引号转换条件过严 | 含单引号值的 JSON 解析失败 | 存在单引号即尝试转换 |
| 日志超限截断丢失尾部错误块 | 根因证据丢失 | 保留头尾各半 |
| mock embedding 对数字敏感 | 分区质量差 | 数字 token 归一化(现已被真实 embedding 取代) |
| 分区过碎 + 错误块被截断 | 分析噪声大/漏错误 | 小块合并 + 可疑度排序 |
