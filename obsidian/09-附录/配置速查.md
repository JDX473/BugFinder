# 配置速查

> 文件: `config/config.yaml`;模板: `config/prompts/`
> 相关: [[与论文的对应关系]] | [[关键设计决策]]

## llm — LLM 调用

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `provider` | `deepseek` | deepseek / openai / mock(mock 无需 key) |
| `base_url` | `https://api.deepseek.com` | 供应商端点 |
| `model` | `deepseek-chat` | 模型名 |
| `api_key_env` | `DEEPSEEK_API_KEY` | 从环境变量读取(勿写入本文件) |
| `timeout` / `max_retries` | 120 / 3 | 请求超时与重试 |
| `price_per_1m_input/output` | 1.0 / 4.0 | 成本估算单价(USD) |

## embedding — Embedding 调用

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `provider` | `openai_compat` | openai_compat / mock |
| `base_url` | DashScope 兼容端点 | ★ 按用户实际端点改 |
| `model` | `qwen3.7-text-embedding` | ★ 用户提供 |
| `dim` | 1024 | 仅 mock 用 |
| `api_key_env` | `EMBEDDING_API_KEY` | 环境变量 |

API 批次上限 20(代码内常量,对齐 qwen API 限制)。

## decoding — 解码策略(论文 §IV-A)

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `default` | `greedy` | greedy / sampling |
| `penalty_threshold_tokens` | 4096 | 超长触发惩罚重启 |
| `penalty_step` | 0.5 | 每次迭代 +0.5 penalty |
| `max_penalty_iterations` | 3 | 最多迭代次数 |
| `sampling.temperature` / `top_p` | 0.9 / 0.6 | SC 采样配置(论文原值) |

## agent — 主循环

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `variant` | `full` | full / react / no_experts / no_jsonregen / no_obsk / no_obs_head |
| `max_steps` | 15 | Pass Rate 定义(论文) |
| `obs_head_chars` | 4000 | OBSK 观察 head 长度 |
| `jsonregen_retries` | 3 | JsonRegen 重试上限 |
| `finalize_required_fields` | 四项 | finalize 必填字段 |
| `error_handling.*` | 开 | 三类错误的开关与阈值(trivial ≥5 字符, min_tools=1) |

## tools — 工具层

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `dedup_ratio` | 0.95 | 模糊去重相似度阈值 |
| `max_obs_chars` | 200000 | 工具返回超长硬上限(保留头尾) |

## log_agent — 日志专家(Algorithm 1)

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `window` | 200 | 分区配对窗口 j−i ∈ (0, 200](论文) |
| `top_k` | 3 | ICP 检索示例数 |
| `max_chunks` | 30 | 分析块数上限(可疑度优先) |
| `min_chunk_lines` | 30 | 更小的块并入相邻块 |
| `jsonregen_retries` / `temperature` | 2 / 0.0 | 分块分析生成参数 |
| `concurrency` | 4 | 分块分析并发 |

## code_agent — 代码专家

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `max_files` | 20 | 递归分析文件上限 |
| `jsonregen_retries` / `temperature` | 2 / 0.0 | 分析生成参数 |
| `repo_name` | advisor service | ★ 目标服务适配时改 |
| `language` / `language_short` | Java / java | prompt 措辞与代码块标记 |

## sc — Self-Consistency

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `method` | `none` | none / tsc / sc(步进) |
| `samples` | 10 | 采样数 K(论文) |
| `aggregate` | `llm` | llm / embedding |
| `temperature` / `top_p` | 0.9 / 0.6 | 采样解码 |

## trajectory — 轨迹记录

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `dir` | `./runs` | JSONL 落盘目录 |
| `save_prompt_text` | true | 记录每步确切 prompt(体积大,排错用) |

## 常用命令

```bash
python -m rcagent --job demo_es_conn_timeout --mock        # mock 跑单轨迹
python -m rcagent --job demo_es_conn_timeout               # 真实跑单轨迹
python -m rcagent --job demo_x --sc tsc --samples 10       # TSC
python -m rcagent --job demo_x --variant react             # 基线变体
python -m rcagent.eval --metrics METEOR,EmbScore --judge   # 批量评估
python -m rcagent.eval --win-rate a.json b.json            # Win Rate 对比
python -m rcagent.env.local --generate                     # 重建 demo 数据
python -m pytest tests/ -q                                 # 测试
```
