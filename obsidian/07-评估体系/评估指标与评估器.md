# 评估指标与评估器

> 相关: [[消融变体与实验设计]] | [[复现进度清单]]
> 代码: `rcagent/eval/`(metrics.py / judge.py / report.py / __main__.py)
> 论文: §IV-C

## 评估体系总览(论文 §IV-C 四类)

| 类别 | 指标 | 用途 |
| --- | --- | --- |
| 语义指标 | METEOR / BERTScore / EmbScore / NUBIA / BLEURT / BARTScore | 预测 vs 标注的文本相似度 |
| 归一化 | NormScore(基线 "Unclear") | 消除指标数值域窄的问题 |
| 轨迹统计 | Pass Rate / Invalid Rate / 轨迹长度 | agent 稳定性 |
| LLM 评估 | G-Correctness / G-Helpfulness(0~10)/ Win Rate | 强模型估计弱模型输出质量 |

## 语义指标(metrics.py)

| 指标 | 实现 | 状态 |
| --- | --- | --- |
| METEOR | nltk 标准(需 wordnet)+ 轻量 fallback(词干匹配) | ✅ 启用 |
| EmbScore | `(1 + cos(Emb(p), Emb(r))) / 2` | ✅ 启用 |
| BERTScore | bert-score 包(deberta-large-mnli) | ⚠️ 需下载 ~1.5GB 权重 |
| NUBIA | nubia-score 包(6-dim) | ⚠️ 需 torch + HF 权重 |
| BLEURT | bleurt 包(需 TensorFlow) | ⚠️ 依赖重,可选 |
| BARTScore | transformers(bart-large-cnn) | ⚠️ 需下载权重 |

权重类指标**延迟导入 + 缺依赖时报清晰错误**(`MetricUnavailable`),
评估 CLI 自动跳过并提示——不会阻塞流水线。

### NormScore(论文公式)

```
NormScore(p,r) = (Score(p,r) − Score(b,r)) / (1 − Score(b,r))
b = "Unclear"(基线内容)
```

- 失败/不完整轨迹的结果**自动填 "Unclear"** 参与计算(论文 baseline 填充);
- 论文注: 部分指标数值域窄(BERTScore ~0.5-0.9),归一化后更可读。

### 统一接口

```python
compute(metric, preds, refs, embedder) -> list[float]   # 逐条分数
mean_std(values) -> (mean, pstdev)                       # 报表 mean±std
```

## 轨迹统计

| 指标 | 定义(论文) |
| --- | --- |
| Pass Rate | 15 步内成功调用 finalize 退出的轨迹占比 |
| Invalid Rate | 无效动作占比,跨轨迹平均(解析失败/工具不存在/参数错/错误检测命中) |
| Trajectory Length | 平均步数 |

数据来源: 轨迹记录的 `invalid_actions` 与 `records` 长度(见 [[Controller-Agent-循环]])。

## LLM 评估器(judge.py)

评估 prompt **照录论文原文**:

```
G-Correctness: "Judge the correctness of the prediction, 0 is completely wrong
                and 10 is well-matched"
G-Helpfulness: "Judge the helpfulness of the prediction, 0 is completely
                misleading and 10 is very helpful"
Win: "Respond with exactly one of: BETTER | WORSE | EQUAL"
```

- 论文用 gpt-4-0613(greedy, 已下线);本项目用 **DeepSeek**(已确认决策);
- 分数解析: 正则提取数字,钳制到 0~10;
- Win Rate = 方法结果被判定优于 ReAct 结果的比例;
- 人工评估(H-Helpfulness 0~5)作为参考指标,界面可简化。

## 评估 CLI

```bash
# 批量评估(跑轨迹 + 语义指标 + 可选 LLM 评估)
python -m rcagent.eval --metrics METEOR,EmbScore --judge --limit 4

# 对比两个已保存结果文件,输出 Win Rate
python -m rcagent.eval --win-rate runs/eval/rcagent.json runs/eval/react.json

# 消融变体
python -m rcagent.eval --variant react --metrics METEOR,EmbScore
```

输出: 论文 Table I~V 风格的 markdown 报表 + 结果 JSON
(预测/标注/轨迹统计,供 `--win-rate` 复用)。
