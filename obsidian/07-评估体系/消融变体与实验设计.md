## 变体系统(单点开关,不复制代码)

`RCAgent.build(cfg, llm, env, variant=...)`,共 6 种:

| variant | 关闭的内容 | 对应论文 |
| --- | --- | --- |
| `full` | 无(全部机制) | RCAgent |
| `react` | JsonRegen + OBSK + 专家工具 + 错误处理 | ReAct 基线 |
| `no_experts` | 日志/代码专家工具 | RQ2: w/o LLM experts |
| `no_jsonregen` | JsonRegen(解析走简化路径) | RQ2: w/o JsonRegen |
| `no_obsk` | OBSK(观察直接截断) | RQ2: ReAct+JsonRegen+experts(无 OBSK) |
| `no_obs_head` | 观察 head(只给快照键) | RQ2: w/o Obs Head |

```python
# 每个开关的落点
use_regen      = variant not in ("react", "no_jsonregen")     # 解析路径
obs_mode       = "no_obsk"|"no_obs_head"|"full"               # 观察形态
detector.enabled = variant != "react"                         # 错误处理
include_experts = variant not in ("react", "no_experts")      # 专家工具
```

设计保证: 消融对比时**唯一变量是被移除的机制**,其余逻辑共用同一份代码
(避免双份实现漂移)。

## 论文实验设计(RQ1~RQ5)与对照

| RQ | 问题 | 实验设计 | 我们的落点 |
| --- | --- | --- | --- |
| RQ1 | RCAgent 整体效果 | full vs ReAct,全部指标 + Win Rate | `--variant full` vs `--variant react` + `--win-rate` |
| RQ2 | 各组件贡献 | 逐个移除组件(消融) | 6 种 variant 全跑 + 报表对比 |
| RQ3 | 轨迹稳定性 | Pass Rate / Invalid Rate / 长度 | 轨迹统计(评估 CLI 自动输出) |
| RQ4 | 生产可用性 | 在线数据集 + 人工评估 | 依赖目标服务数据 |
| RQ5 | SC 规模与方式 | K=1/5/10/20/30 × {SC, TSC} × {embedding, LLM} | `--sc tsc --samples K`,10 次运行取 mean±std |

## 预期结果参照(论文 Table I/IV,复现目标为相对趋势)

| 方法 | METEOR(root cause) | Pass Rate | Invalid Rate |
| --- | --- | --- | --- |
| RCAgent | 15.15 | 99.38% | 7.93% |
| w/o LLM experts | 9.60 | 92.55% | 16.24% |
| w/o JsonRegen | 13.89 | 85.71% | 18.75% |
| w/o Obs Head | 12.27 | — | — |
| ReAct+JsonRegen+experts | 12.37 | 96.89% | 18.34% |
| ReAct | 6.44 | 86.33% | 22.82% |

**消融梯度(要复现的方向)**: LLM experts > JsonRegen > OBSK(观察头);
移除 experts 时几乎退回 ReAct 水平。

## 实验操作手册

```bash
# 1. 准备(生成数据,已就绪)
python -m rcagent.env.local --generate

# 2. 逐变体评估(后台跑,真实模型每个 ~10-15 分钟)
python -u -m rcagent.eval --variant full  --metrics METEOR,EmbScore --out runs/eval/full
python -u -m rcagent.eval --variant react --metrics METEOR,EmbScore --out runs/eval/react
python -u -m rcagent.eval --variant no_experts   --metrics METEOR,EmbScore --out runs/eval/no_experts
python -u -m rcagent.eval --variant no_jsonregen --metrics METEOR,EmbScore --out runs/eval/no_jsonregen
python -u -m rcagent.eval --variant no_obsk      --metrics METEOR,EmbScore --out runs/eval/no_obsk
python -u -m rcagent.eval --variant no_obs_head  --metrics METEOR,EmbScore --out runs/eval/no_obs_head

# 3. Win Rate(full vs react)
python -m rcagent.eval --win-rate runs/eval/full/results.json runs/eval/react/results.json

# 4. SC 规模实验(K 扫描,每 K 跑 10 次取 mean±std)
for k in 1 5 10 20 30; do
  python -u -m rcagent --job demo_x --sc tsc --samples $k --out runs/sc/k$k
done
```

## 已知限制(诚实标注)

1. **数据不同**: demo 4 场景 vs 论文 161+36,数值不可比,目标为**相对趋势**;
2. **模型更强**: DeepSeek API 强于论文 Vicuna-13B,消融梯度可能被压缩
   (论文 §VI 承认 ChatGPT 也会出错,但弱模型上机制收益更明显);
3. **ReAct 基线差异**: 我们的 react 变体是 zero-shot
   (论文 ReAct 基线带 few-shot),对比时以论文消融行的"ReAct+JsonRegen+experts"
   口径更接近;
4. 权重类指标(BERTScore/NUBIA/BLEURT/BARTScore)未启用时,
   主指标用 METEOR + EmbScore。
