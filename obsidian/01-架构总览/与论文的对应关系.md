## 论文算法 ↔ 实现细节对照

### Algorithm 1(日志专家)逐行对照

| 论文步骤 | 实现位置 | 说明 |
| --- | --- | --- |
| 1. S ← split L | `log_agent.py` `_run_uncached` | `splitlines()` |
| 2. v_s ← EMBEDDINGMODEL | `partition.py` `semantic_partition` | 行级批量 embedding(API 批次 20) |
| 4-8. 窗口配对 w=sim×exp(−d) | `partition.py` | `j-i ∈ (0, 200]`,负相似度截断为 0 |
| 10. Louvain 聚类 | `partition.py` | `community_louvain.best_partition` |
| 11. 贪心去重叠(连续化) | `partition.py` `greedy_overlap_removal` | 保留最长段,其余段切换为邻居标签 |
| 15-21. ICP 检索与填充 | `knowledge.py` `build_icp` | 相似度排序,累积长度 ≤ max_chars |
| 22. LLM 分析 | `log_agent.py` `_analyze_chunk` | 零样本 CoT + 强制逐字复制证据 |
| 25. 幻觉过滤 | `log_agent.py` `_evidence_ok` | `LEVENSHTEIN(e,p) < len(p) − 0.9·len(e)` |
| 31. LLM 总结 | `log_agent.py` `_summarize` | 合并全部幸存分析 |
